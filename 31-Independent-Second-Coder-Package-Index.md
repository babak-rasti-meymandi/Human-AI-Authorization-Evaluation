# Independent Second-Coder Review Package — Index

**Version:** 1.0  
**Prepared:** 2026-11-02  
**Status:** Prepared for external invitation; not yet reviewed by an independent coder  
**Project:** BAES Pilot Evaluation — Phase 1 documentary coding verification

## Purpose

This package enables an independent second coder to review the investigator-side Phase 1 documentary coding without seeing the current ratings and rationales in advance.

## Package contents

1. [Review Protocol v1.0](28-Independent-Second-Coder-Review-Protocol-v1.0.md) — scope, blinding, source boundaries, scales, coding procedure, deliverables, disagreement handling, and claim limits.
2. [Blank Independent Coding Worksheet](29-Independent-Coding-Worksheet-Blank.md) — separate Axis A and Axis B coding tables for all historical C1–C20 criteria.
3. [Invitation Email Draft](30-Independent-Second-Coder-Invitation-Email.md) — email and short direct-message versions.

The protocol specifies the exact S01-A, S01-B, and common artifact paths. The reviewer should use the historical criteria, not the separate Proposed v0.1 set.

## Blinding rule

Do not provide the reviewer with investigator-side coding, adversarial calibration, audit, or synthesis documents before the independent worksheet is completed and dated. See Protocol §2 for the exact exclusion list.

## What this package does not claim

- No independent reviewer has yet been recruited or completed a review.
- No inter-rater reliability statistic has been established.
- No human reviewer-performance or Phase 2 study has been conducted.
- The package does not establish BAES validity, novelty, effectiveness, or superiority.
- The synthetic S01 scenarios are not historical or real organizational events.

## Next operational steps

1. Identify one qualified independent researcher or practitioner.
2. Send the invitation individually, initially without the investigator coding files.
3. If interested, share this package and confirm scope, schedule, terms, and attribution preferences.
4. Obtain a dated independent worksheet and preserve it unchanged.
5. Only then compare it with investigator coding and create a separate disagreement/adjudication record.
