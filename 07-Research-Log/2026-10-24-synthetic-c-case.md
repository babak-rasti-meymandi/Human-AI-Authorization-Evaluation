# Research Log — 2026-10-24: Synthetic C Case

## Decision

Use a small synthetic C99 module rather than requesting or publishing the researcher's existing source code. This avoids unnecessary exposure of personal code and avoids making the study depend on an unreviewed third-party or private code sample.

## Artifact created

The `06-Code-Sample/` directory contains a baseline function, a proposed behavior-changing variant, a characterization test, a boundary test, a runner, and the initial result record.

The function contract is to count **complete groups**. The proposed variant rounds up to count groups needed to accommodate all items. These are different contracts. The proposed variant retains the same function name and signature, making the semantic change easy to miss if reviewers inspect only the interface or rely on the initial test suite.

## Local verification

On 2026-10-24, `sh run-tests.sh` was executed from `06-Code-Sample/` using `cc (Debian 14.2.0-19) 14.2.0` with strict C99 warning flags. The baseline and proposed variant both passed the characterization suite. The baseline passed the boundary test; the proposed variant failed it as expected. Exact output is recorded in `06-Code-Sample/RESULTS.md`.

## Interpretation boundary

This is a constructed reproducibility demonstration. The proposed change was authored for this scenario; it is not claimed to be generated by a specific AI system. The local test run is not a human-review result and does not show whether Condition A or Condition B performs better.
