# Evidence and Results Register

**Status:** Initial register guidance; no evaluation results recorded.

## Purpose

This directory is reserved for traceable scenario evidence, reviewer records, analysis, and results. It must distinguish source artifacts from interpretations and conclusions.

## Evidence register fields

For each item, record:

| Field | Description |
|---|---|
| Evidence ID | Stable identifier, e.g. H1, D01, or R01 |
| Scenario / variant | S01, S01-A, S01-B, or control |
| Artifact name | Descriptive filename or record title |
| Type | Instruction, baseline, diff, test, review, authorization, analysis, etc. |
| Provenance | Who or what produced it, and how it was obtained |
| Version / date | Version and date where available |
| Status | Planned, collected, checked, excluded, or superseded |
| Integrity / traceability note | How the artifact is tied to the scenario version |
| Access / rights note | Whether publication is permitted and whether restrictions apply |

Do not invent evidence IDs or state that an artifact was collected before it exists.

## Reviewer records

Each reviewer record should identify:
- reviewer identifier or role, with consent and privacy respected;
- protocol version;
- scenario variant and evidence packet version;
- criterion-level judgments;
- exact evidence references;
- rationale and unresolved ambiguity;
- any protocol deviation.

## Results discipline

- Keep raw evidence separate from reviewer interpretation.
- Keep reviewer interpretation separate from the researcher's synthesis.
- Preserve disagreements and negative findings.
- State when evidence is absent, unavailable, or not collected.
- Do not publish personal, confidential, or licensed material without appropriate permission.
- Do not claim independent replication or review unless it occurred.

## Initial status

No formal evaluation has been conducted and no empirical findings are claimed. Populate this directory only when the relevant artifacts or results have actually been created and reviewed.
